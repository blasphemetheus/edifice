# History

Documents that record a point in time: session handoffs, audits, and
benchmark results for code that has since changed or been removed. They are
kept because later decisions cite them. Nothing here describes the current
code; for that, see `docs/TESTING.md`, `docs/kernel_tier_benchmarks.md`, the
guides, and the CHANGELOG.

| File | What it was |
|---|---|
| `ARCHITECTURE_ROADMAP.md` | February 2026 roadmap, written at 147 architectures. All tiers were completed. |
| `HANDOFF_BOT_RUNTIME.md`, `HANDOFF_STEP_JIT_INTERP.md` | July 2026 worktree handoffs for the stateful step path and interpretability fits. |
| `INTERP_AUDIT_2026-07-15.md` | Audit of the interpretability modules against the LEACE standard. |
| `architecture_completion_audit.md` | ExPhil-focused review of what was complete and what still needed validation (October 2026). |
| `architecture_corrections_2026-10-26.md` | Corrections made during the October 2026 architecture review. |
| `composability-audit.md`, `ecosystem_audit.md`, `nx_usage_audit.md` | Code audits from the Nx 1.0 upgrade. |
| `cuda_nif_bridge_results.md`, `exla_custom_calls_results.md` | Benchmark notes for the CUDA NIF bridge (removed 2026-10-26) and the first EXLA custom calls. Superseded by `docs/kernel_tier_benchmarks.md`. |

Plans that are still open live in `docs/plans/`.
